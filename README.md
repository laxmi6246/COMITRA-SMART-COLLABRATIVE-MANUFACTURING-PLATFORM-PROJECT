# CoMitra – Smart Collaborative Manufacturing Platform

## About the Project
CoMitra is a web-based platform that helps manufacturers collaborate to complete large manufacturing orders. It identifies suitable manufacturing partners using a Multi-Criteria Weighted Scoring Algorithm and supports order allocation, production tracking, and quality management.

## Features
- **Dashboard:** Overview of manufacturing activities.
- **Business Profiles:** Register and manage manufacturer details.
- **Find Partners:** Match manufacturers using weighted scoring.
- **Post an Order:** Create manufacturing orders.
- **Order Allocation:** Distribute orders among suitable partners.
- **Production Tracking:** Monitor manufacturing progress.
- **Quality Management:** Manage quality checks.
- **Agreements:** Support collaboration agreements.
- **Analytics:** View manufacturing performance insights.
- **Settings:** Manage platform settings.

## Algorithm
CoMitra uses a Multi-Criteria Weighted Scoring Algorithm to rank manufacturing partners based on:

- Production Capacity – 30%
- Machinery Compatibility – 25%
- Quality Rating – 20%
- Delivery Reliability – 15%
- Location – 10%
